Destroyed

Everybody else

The plate is destroyed on the camera itself, before anything leaves it. What reaches the server is an anonymous dot with no photo and no plate.

Running a camera

There is nothing to install and no account to make. It runs in a browser tab on a phone you have already stopped using, propped in a window.

The detection runs on the phone, not on a server. That matters more than it sounds: if the video were uploaded for a server to look at, there would be a video feed to intercept. There is not one.

  • Works on an old phone, a laptop webcam, or a USB camera
  • No account, no sign up, no app store
  • Your camera's exact location is never published, only the street it watches
  • You can shut it off and take your camera out of the network at any time

Already have cameras outside? (shops, workshops)

If a camera already watches the street outside your shop or house, it can feed the map without you buying anything or changing how it works. The video never leaves your network — only a crop of a vehicle, shrunk below the size a number plate can be read at.

  • Start here: configure your RavenMap hub and set up the camera there. Type your address, drop the pin, and point the cone at the road.
  • Then run it: use the relay tooling from your configured RavenMap checkout on any machine with pip install opencv-python onnxruntime numpy
  • Works with RTSP / ONVIF cameras — Hikvision, Dahua, Reolink, Axis, UniFi and most others
  • No graphics card needed: the vehicle spotting is light, and deciding “patrol car or not” happens on our hardware, not yours

Want an always-on camera?

The other route, and the heavier one: a spare PC with a webcam running the full detector locally. It tells a patrol car from an ordinary one on the machine and reads plates, so nothing waits on us. One command sets it up and starts contributing to the map:

  • Windows: run the node installer from your configured RavenMap checkout after setting RAVEN_HUB and RAVEN_REPO.
  • Linux (help us test): run the node installer from that same configured checkout; no upstream repository is selected implicitly.
  • Everything still runs on your machine — only detections leave it, never video
  • It is a big install: about 2.5 GB of models, and it wants a PC left on, ideally with an NVIDIA card. If you already have an IP camera, the IP camera option above is far lighter.
