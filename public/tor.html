RavenMap over Tor 🧅

The same map, reachable as a Tor onion service — harder to block, harder to watch who's looking.

Why an onion address

A privacy project shouldn't only live at an address a network can block or a watcher can see you visit. The Tor onion mirror serves the same public map, but the connection stays inside the Tor network end to end: no exit node, no ISP or wifi operator seeing that you loaded SparrowMap, and nothing to censor at the DNS or the border.

It's the same read-only public map — government vehicles only, same privacy rules. Just a more resilient way in.

What browser you need

Tor Browser (free, the standard way) — desktop and Android. Paste the onion address into it and you're on.

Get Tor Browser

Brave also works — open a “New private window with Tor” and paste the address. Handy if you already use Brave.

Get Brave

On iPhone, use the Onion Browser app (App Store) — Apple doesn't allow the official Tor Browser there.

Quick start

  1. Install Tor Browser (or open Brave's Tor window).
  2. Copy the onion address above.
  3. Paste it into the address bar and go.
  4. Bookmark it. That's it — same map, private path.

The onion mirror is the same public, read-only map. Only government vehicles are ever published; civilian plates are destroyed at the camera, on Tor or off it.
