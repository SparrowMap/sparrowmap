How it works. The network places a source where paired detector hardware reports a radar emission — it is not a tap, and it fades on its own in a few minutes. Ka band (33–35 GHz) is essentially police-only, so it reads red. K band (24 GHz) is shared with cars' own blind-spot radar, so it is dimmer and wants a second reporter to trust. One detector shows you strength; the real red dot on a road tightens as several drivers see the same source from different spots.
